============================================================
CURRENT WEBSITE SETTINGS — REFERENCE
============================================================

The current integrated settings bridge supports ONLY:

1. appointmentButtonVisible
   Value type: true or false
   Effect: hides/shows the main appointment booking button and floating WhatsApp button.
   Hiding does not delete their HTML or booking links.

2. marqueeText
   Value type: text
   Effect: changes the text in the existing announcement marquee.

3. animationSpeed
   Value type: number from 0.1 to 3
   Effect: adjusts playback speed for targeted marquee/cosmos animations.

Any request outside these three settings is a MANUAL CODE CHANGE. The website will not interpret the English description or implement it automatically.


============================================================
HOW TEMPORARY OVERRIDES WORK
============================================================

Priority while an override is active:
  Active temporary override > Permanent defaults > Built-in fallback.

At or after the expiry time:
  The override stops applying.
  The permanent default becomes effective again.
  The permanent default file is not changed.

If multiple enabled overrides target the same setting at the same time:
  The override with the latest startAt wins.
  A conflict warning is shown in the browser console.

A temporary override only affects visitors after the updated configuration file is deployed to the website. The browser checks settings on page load, when the tab becomes visible, and every 30 seconds while open. If the page is closed at expiry, the default is used the next time the page is opened or refreshed.

Use explicit India offsets in timestamps, for example:
  2026-10-31T09:00:00+05:30

This is browser-side display logic, not a Windows scheduler, security mechanism, or GitHub publishing tool.


============================================================
WHERE THE REAL SETTINGS ARE STORED
============================================================

Keep this folder structure beside index.html:

website-root/
  index.html
  update.txt
  configuration/
    defaults.json
    temporary_overrides.json

defaults.json
  Stores permanent values. Edit only when you want to change the normal/default behaviour.

temporary_overrides.json
  Stores temporary values and their start/end timestamps. Set enabled:false to keep an override OFF.

The form above does not automatically update either JSON file. After completing the form, manually transfer the supported setting into the appropriate JSON file. For unsupported changes, manually edit the relevant HTML/CSS/JavaScript in your Working Clone.
