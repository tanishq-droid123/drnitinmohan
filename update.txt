## IMPORTANT

- All selected changes will use the same start and end time.
- A temporary change will replace the normal setting only during its active period.
- When it expires, the website returns to its previous permanent setting.
- Changes remain OFF until explicitly activated.
- Some changes require manual website editing; they cannot all be controlled through the current settings system.
- Filling this sheet does not itself change the live website. The website manager must review, implement, test and approve publishing.

One important distinction: Appointment visibility, announcement text and animation speed are currently supported by your settings bridge. Photo, gallery, text and design changes still need manual editing. The form can request all of them, but it cannot automatically implement those unsupported changes.s
